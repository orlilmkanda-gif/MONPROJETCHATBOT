# MWALIMU – Version 0.1

## Description
MWALIMU est un assistant pédagogique scolaire.
Il aide les élèves à comprendre les notions sans donner directement les réponses.

## Fonctionnalités
- Réponses conditionnelles selon le message
- Approche pédagogique progressive
- Respect de l’autorité de l’enseignant
- Fonctionnement sans IA

## Statut
Version stable de référence.
Toute évolution future devra respecter cette base.
